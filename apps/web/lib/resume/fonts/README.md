Fonts embedded in résumé PDFs (lib/resume/pdf.ts), copied from the @fontsource packages the app
already uses. Both are under the SIL Open Font License 1.1.

- atkinson-400.woff, atkinson-700.woff: Atkinson Hyperlegible Next, Latin subset.
- noto-sans-sc-400.woff: Noto Sans SC, simplified Chinese subset (also covers Latin), for text
  Atkinson has no glyph for. Only the glyphs a résumé uses are embedded.
