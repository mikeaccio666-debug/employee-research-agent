# 门框原型：5 人测试脚本

| 项 | 内容 |
|---|---|
| 原型 | `/design/doorframe`（设计简报 §5B、屏幕 S22） |
| 目的 | 决定"门框"要不要当求职者登录后的主界面 |
| 人数 | 5 人：3 位应届生或在校生，2 位工作 3 年以上、想转行的人 |
| 时长 | 每人 30 分钟，线上共享屏幕；至少 2 人用手机 |
| 日期 | 2026-11-09 起草 |

## 要回答的四个问题

1. 不解释的情况下，用户能不能在 10 秒内说出"实线、粉笔、虚线"各是什么意思？
2. 用户敢不敢点"对"？他们知道点"对"之后什么会发生、什么不会发生吗（不会替他们对外发东西）？
3. "你不在时"的便签，是让人觉得被照顾，还是被打扰？
4. 转行者切换"以前的方向 / 新方向"之后，觉得翻译可信吗？会去点出处吗？

## 流程

**开场（3 分钟）**：说明这是原型，人物和数据都是虚构的，我们测的是设计不是测他们；请他边做边说出想法。

**任务 1：看懂（5 分钟）**。打开页面，选 Mei Chen，什么都不点。问："这页在告诉你什么？哪一条是你接下来要做的？"
记录：是否提到"下一步"、是否把虚线理解成"还没发生"。

**任务 2：三个手势（8 分钟）**。
- "这条下一步你觉得合适，就定下来。" 然后："假设你做到了。"（看是否找到"对"和"做到了"）
- "上面那条'投 5 家公司'，你想改成先投 3 家远程的。"（看是否找到"改"，手机上是否先点那一行）
- "'入职 90 天'你现在不想看到。"（看是否用"不要"，是否发现能撤销）
- 手机上：请他试着左右滑一条。

**任务 3：你不在时（5 分钟）**。"你昨晚没上线，agent 做了几件事。" 看他是否点开便签，怎么处理失败的那一条（重试 / 跳过）。

**任务 4：转行者（5 分钟）**，只给转行的 2 位。切到 Daniel Wu，在两个方向间切换。问："这些新说法你信吗？哪一句你会想看出处？缺口那两条对你有用吗？"

**收尾（4 分钟）**：
- "如果登录后第一屏就是这个，你会每周回来几次？为什么？"
- "最不舒服的一个地方是什么？"
- "跟你现在用的求职工具（LinkedIn、简历工具、一亩三分地等）比，这个最像什么、最不像什么？"

## 怎么判断

- **当主界面**：至少 4/5 能自己说清实线和虚线的意思，至少 4/5 不靠提示完成任务 2，没有人担心"点了对会不会替我发出去"。
- **改了再测**：3/5 左右，问题集中在一两处（比如手势找不到、便签太吵）。
- **只当视觉母题**：多数人看不懂，或者觉得没必要每周回来。

## 已知局限

- "改"不会真的调用模型，用的是预写好的结果；"开始"只演示到第一步。
- 远处的铅笔线要悬停、聚焦或点一下才出现按钮，读屏用户需要先进入那一行（Y / E / N）。
- 界面只有中文版。
